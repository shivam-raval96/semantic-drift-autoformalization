Does learning a notation's name first help a model translate into it?

Stage 2 · Llama‑3.1‑8B · translation (story → formal notation)

Question

Stage 1 showed a model can learn to recognize three formal notations by an arbitrary name. Stage 2 asks the harder question: does that familiarity help the model actually write the notation from a plain-language story, and how far does a single translation skill carry — to a notation it was never trained to produce, and to a story style it never saw?

The setup in one picture

  • Every training example is a (story, notation) pair. The model reads the story and must produce the matching formal statement; loss is on the answer only.
  • Staged runs start from the stage-1 model (already familiar with the notations). The direct run starts from the plain base. Everything else is identical, so any difference is the familiarity.
  • One story theme (tea) and one whole notation (RG-4, a bracketed prefix form (⋆ left right)) are held out of all training, to test carry-over.

What we are looking for

Whether faithful translation is a general skill or a per-notation one: if T1 carries to the unseen RG-4 and the unseen tea theme, the skill generalizes; if it collapses there, the model learned a specific notation, not translation. Staged (T1) vs direct (D0) says whether recognizing a notation first buys any of that.
