Experiment 3 — PCA / activation structure

Qwen/Qwen3-4B, 52 laws × 6 surface forms (four story themes, literal NL, Rigid Grammar) = 312 texts. Does activation space contain structure that tracks which law a problem is, independent of how it is worded?

The short version

Yes. By the middle of the stack the model holds a representation of which law a problem is that survives a complete change of wording — we decode it at 86% against a 1.9% chance rate, and it beats every baseline we can build without the model.

What we cannot yet say is whether the model uses that representation when it formalizes. Meanwhile the thing that actually moves accuracy is unrelated to representation quality: it is how many thinking tokens the model is allowed to write.

1. The same law is recognisable across surface forms

Positive result

For each text we find its nearest neighbour in the residual stream, excluding every candidate that shares its surface form, and score a hit if that neighbour encodes the same law. In plain terms: pick up a story about grafting, throw away everything else worded like it, and ask whether the closest thing left is the same law wearing a different costume.

Two controls rule out the cheap explanations:

  • It is not shared vocabulary. The four story themes share almost no words by construction, and a TF-IDF baseline gets 4.8%.
  • It is not just problem size. Restrict the search to laws with the same operation count, so size carries no information, and retrieval is still 92.8% against a 13.5% baseline. The model represents which law it is, not how big it is.

2. Surface form still dominates the raw geometry

Context

The law signal above is real but not what you see first. In a plain 2D projection, 72–100% of the variance is surface form — essentially one axis separating Rigid Grammar from natural language. The four story themes pile on top of each other and literal NL sits apart from both. There is no clean story → literal → RG ladder.

3. Accuracy is set by thinking budget, not comprehension

Key mechanism

Giving the model more thinking tokens takes it from 15% to 44% correct on the same 52 problems.

Why this matters.

The representation of the story is provably identical across every row of that table — thinking happens after the story tokens, so it cannot reach back and change how they were read. The information needed was already there while the model was failing 85% of the time. Extra thinking buys serial room to unpack the representation, not better comprehension of the problem.

4. What we still do not know

Open

Everything above is decodability: the law is in there and we can read it out. It does not show the model reads from it when it formalizes. The two sections built to test that — a faithfulness probe and a causal law transplant — ran out of GPU memory and produced nothing this run. The fix is known and cheap, and experiment 8 attacks the same question from another angle.

Next, in order:

  1. Fix the memory blowup and run the causal tests, at thinking budget 256.
  2. Check that the complexity gradient in activation space is not just text length, which tracks operation count at r > 0.93.
  3. If the transplant comes back null, retry it at the smallest budget that clears the floor — a long thinking trace lets the model attend back to the original, unpatched text.
